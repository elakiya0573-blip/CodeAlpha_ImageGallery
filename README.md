# CodeAlpha Image Gallery

A responsive and interactive **Image Gallery** developed using **HTML, CSS, and JavaScript** as part of my **CodeAlpha Frontend Development Internship**.

## 📌 Project Overview

This project is a responsive image gallery designed to provide a smooth and user-friendly experience for viewing and browsing images. It includes image navigation, category filtering, and a lightbox view.

## ✨ Features

* 🖼️ Responsive image gallery
* 🔍 Lightbox view for enlarged images
* ⬅️ Previous and Next navigation
* 🎯 Image category filtering
* ✨ Smooth image transitions
* 📱 Responsive design for different screen sizes
* 🖱️ Interactive user interface

## 🛠️ Technologies Used

* **HTML5** – Structure of the webpage
* **CSS3** – Styling, layout, animations, and responsive design
* **JavaScript** – Image navigation, filtering, and interactive functionality

## 📂 Project Structure

```text
CodeAlpha_ImageGallery/
│

│
└── images/
    ├── image1.jpg
    ├── image2.jpg
    ├── image3.jpg
    └── image4.jpg
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. Explore the gallery using the available navigation and filtering options.
