# CodeAlpha Image Gallery

A responsive and interactive **Image Gallery** developed using **HTML5, CSS3, and JavaScript** as part of my **CodeAlpha Frontend Development Internship**.

## 📌 Project Overview

The CodeAlpha Image Gallery is a modern and responsive web application designed to display and browse images in an interactive way.

The project provides users with an easy-to-use interface for viewing images, navigating between images, filtering images by category, and opening images in a larger lightbox view.

The gallery is designed to work smoothly across different screen sizes, including desktops, tablets, and mobile devices.

## ✨ Features

* 🖼️ Responsive image gallery
* 🔍 Lightbox view for viewing images in a larger format
* ⬅️ Previous and Next navigation
* 🎯 Category-based image filtering

## 🚀 How to Run the Project

### Option 1 — Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Make sure the `images` folder is in the same directory as `index.html`.
4. Open `index.html` in a web browser.
5. Explore the image gallery.

### Option 2 — Using Live Server

If you are using Visual Studio Code:

1. Open the project folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
5. The gallery will open in your browser.
